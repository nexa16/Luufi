# Luufi

Private persönliche Planungszentrale. Der Quellcode ist öffentlich; Daten und Anhänge bleiben auf einer privaten Sites-Instanz.

Der neue Aufbau bietet eine deutsche Grundlage mit geschütztem MCP-Zugang und versionierten Richtlinien. Eigenständige Projektideen lassen sich anlegen, lesen, bearbeiten und bestätigt löschen. Browser und MCP verwenden denselben Service mit Revisionen und sicheren Wiederholungen. Codex verwaltet Projekte, geordnete Milestones und versionierte Auftragsentwürfe über MCP. Die deutsche Oberfläche zeigt Projekte, Konfiguration und Milestones. Feedback, Medien und der Freigabe-/Auslieferungslifecycle sind noch nicht implementiert.
