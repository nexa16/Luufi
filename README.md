# Luufi

Private persönliche Planungszentrale. Der Quellcode ist öffentlich; Daten und Anhänge bleiben auf einer privaten Sites-Instanz.

Der neue Aufbau bietet eine deutsche Grundlage mit geschütztem MCP-Zugang und versionierten Richtlinien. Eigenständige Projektideen lassen sich anlegen, lesen, bearbeiten und bestätigt löschen. Browser und MCP verwenden denselben Service mit Revisionen und sicheren Wiederholungen. Projekte können über MCP registriert und konfiguriert werden. Weitere Projektplanung und Medien sind noch nicht implementiert.
