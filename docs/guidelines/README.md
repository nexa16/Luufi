# Zentrale Richtlinien

Die versionierten Quellen sind [Dokumentation](documentation.md), [Planung](planning.md), [Umsetzung](implementation.md) und [Datenzugriff](data-access.md).

Der native MCP-Endpunkt liefert Kennung, Version, vollständigen UTF-8-Inhalt und SHA-256. Veröffentlichte Versionen werden nicht überschrieben. Datenzugriff und Umsetzung besitzen Version 1.0.1, Planung und Dokumentation Version 1.0.0. Datenzugriff 1.0.1 dokumentiert den freigegebenen Windows-GitHub-Anmeldeablauf. Umsetzung 1.0.1 übernimmt den ausdrücklichen Nutzerwunsch nach weniger Coverage-Läufen und niedrigeren Gates. Das öffentliche Regelwerk enthält keine Zugangsdaten.
